# Ticket Pilot — Lab & TTM Reader 0.2.0

โหมด Local Lab เดิมใช้กับ http://127.0.0.1:5208/ หรือ http://localhost:5208/ ส่วน popup รุ่นใหม่ตรวจหน้าโซน TTM ตามผู้ใช้กดได้ ดู [คู่มือ TTM Reader](TTM-READER.md)

รุ่นนี้เพิ่มสิทธิ์ `activeTab` และ `scripting` สำหรับเข้าถึงแท็บชั่วคราวหลังผู้ใช้กดไอคอน ไม่เพิ่ม host permissions หรือ content script ถาวรบน TTM ต้อง Reload/อัปเดตส่วนขยายก่อนใช้ และยังต้องตรวจผลกับหน้า TTM จริงหลังอัปเดต

## ลองทันทีโดยไม่ติดตั้ง

1. รัน `npm start` จากโฟลเดอร์หลัก
2. เปิด http://127.0.0.1:5208/
3. กด **ลองแผงส่วนขยาย · ไม่ต้องติดตั้ง**
4. แผงลอยมุมขวาล่างจะเปิดขึ้น เลือก 2 ใบ โซนหลักและสำรอง แล้วกดเริ่ม
5. ผู้ช่วยจะเลือกโหมดเลือกเองบนเว็บ กดเข้าคิว รอสิทธิ์ อ่านปุ่มที่นั่งแล้วคลิกที่ติดกัน จากนั้นกดล็อก
6. เมื่อเห็น “ล็อกแล้ว” ให้ตรวจรายละเอียดบนเว็บและกดยืนยันเอง หรือกดหยุดในแผงเพื่อปล่อยสิทธิ์

ตัวอย่างในหน้าเว็บใช้ `content.js` ไฟล์เดียวกับ extension จริง แต่ไม่ถือว่าได้ติดตั้ง Chrome extension แล้ว

## ติดตั้งส่วนขยายจริงด้วยตนเอง

1. เปิด Chrome แล้วพิมพ์ `chrome://extensions` ใน address bar
2. เปิด **Developer mode**
3. กด **Load unpacked** / **โหลดส่วนขยายที่แตกไฟล์แล้ว**
4. เลือกโฟลเดอร์ `ticket-lab/extension` ที่มี `manifest.json` (หากดาวน์โหลด ZIP ให้แตกไฟล์ก่อน)
5. เปิดเว็บทดสอบ หรือรีเฟรชหน้าเดิม แผงผู้ช่วยจะเปิดขึ้น
6. หลังแก้โค้ด extension ให้กด Reload ที่รายการส่วนขยาย แล้วรีเฟรชเว็บทดสอบ

ถ้าติดตั้งจริงแล้ว ไม่ต้องกดปุ่มตัวอย่างในเว็บอีก ระบบป้องกันการเปิด controller ซ้อนกัน

## สิทธิ์และขอบเขต

- ไม่มี `cookies`, `debugger`, `storage`, `webRequest` หรือสิทธิ์ `<all_urls>`
- content script ประกาศเฉพาะ HTTP บน `127.0.0.1` และ `localhost`; Chrome match patterns ไม่แยกพอร์ต จึงตรวจพอร์ต **5208**, ชื่อหน้า และตัวควบคุมของ Lab อีกครั้งในโค้ดก่อนทำงาน
- โหมด Lab เดินขั้นตอนใน DOM ของเว็บทดสอบ โหมด TTM อ่านชื่องาน/รอบ/ตารางคงเหลือที่มองเห็น และเปลี่ยน dropdown รอบเฉพาะเมื่อผู้ใช้กด ไม่เรียก API ภายใน ไม่อ่านรหัสผ่านหรือข้อมูลชำระเงิน
- ใช้รหัสผู้ซื้อทดสอบของหน้าเว็บ ไม่ใช้เลขบัตรประชาชน
- เมื่อจองตัดหน้าจะตรวจโซนสำรองที่ผู้ใช้เลือกไว้เพียงหนึ่งโซน ไม่ยิงซ้ำไม่จำกัด
- ย่อแผงไม่ใช่หยุด ใช้ปุ่ม “หยุดและปล่อยสิทธิ์” เพื่อยกเลิก ถ้าเซิร์ฟเวอร์ขัดข้องต้องตรวจสถานะหน้าเว็บก่อนทำต่อ
- stylesheet ของแผงเสิร์ฟจาก server โปรเจกต์นี้ (`/pilot-panel.css`) ต้องรัน server เวอร์ชันที่มี route นี้
- TTM Reader ยังไม่เลือกจำนวน/ที่นั่ง ไม่ล็อกบัตรหรือยืนยันจอง ไม่มีตัวเชื่อม AllTicket และไม่ข้ามคิว

## โครงสร้าง

`manifest.json` + `content.js` + popup เป็น extension จริง; `/pilot-panel.js` และ `/pilot-panel.css` ในเซิร์ฟเวอร์ใช้สำหรับ preview โค้ดเดียวกันเท่านั้น ไม่ต้องเพิ่ม npm package
