# Ticket Pilot — สรุปความคืบหน้า

อัปเดต 30 ตุลาคม 2569 (Asia/Bangkok)

## สถานะล่าสุด

- โปรแกรม Lab: รุ่น 1.0.0 สำหรับทดสอบบนเครื่อง
- ส่วนขยาย Chrome: Ticket Pilot — Lab & TTM Reader รุ่น 0.2.0
- ยังไม่ใช่บอตจองบัตรจริงที่ผ่านการทดสอบครบขั้นตอน
- ตัวเลข 25% ที่เคยรายงานเป็นการแบ่งงาน 4 ด่านแบบคร่าว ๆ ไม่ใช่สัดส่วนงานวิศวกรรมที่วัดได้ หรือโอกาสได้บัตร ให้ยึดหลักฐานรายฟังก์ชันด้านล่าง

## ทำเสร็จและตรวจแล้ว

### สนามทดสอบบนเครื่อง

มีระบบคิว FIFO, สิทธิ์เข้าซื้อ, ผังที่นั่ง, ตัวช่วยเลือกที่ติดกัน 2 ใบ, ล็อกที่นั่งชั่วคราว และยืนยันรายการทดสอบ รองรับการทดสอบผู้ซื้อแย่งที่นั่งกันและป้องกันการยืนยันรายการซ้ำ ข้อมูลเป็นข้อมูลจำลองใน RAM และเริ่มใหม่เมื่อรีสตาร์ต

### ตัวอ่าน TTM 0.2.0

หลังผู้ใช้อนุญาต ได้อัปเดตส่วนขยายใน Chrome และทดสอบอ่านบนแท็บ TTM จริงเมื่อ 30 ต.ค. 2569 สำหรับงาน Moonshadow : The Afterglow Fan Party and After Party (Rerun) อ่านชื่องาน รอบ FAN PARTY ที่เลือกอยู่ และตาราง RERUN E-TICKET: Available ได้สำเร็จ

การทดสอบจริงนี้ไม่ได้เปลี่ยนรอบ เลือกที่นั่ง ล็อกที่นั่ง ยืนยันจอง หรือชำระเงิน และไม่พิสูจน์ว่ามีที่นั่งติดกัน

ส่วนขยายอ่านเมื่อผู้ใช้กด รองรับเฉพาะหน้า HTTPS บน booking.thaiticketmajor.com/booking/3m/zones.php ใช้ activeTab และ scripting ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์ของเรา ไม่อ่านคุกกี้หรือส่งออกพารามิเตอร์ URL ที่อาจมี token

## ผลทดสอบ

ผลที่บันทึกไว้ของรุ่นนี้: automated tests ผ่าน 18 กรณี ครอบคลุมระบบ Lab และขอบเขตตัวอ่าน TTM ส่วนการเปลี่ยนรอบผ่าน popup ตรวจบน fixture ของเราแล้ว แต่ยังไม่ทดสอบกับ TTM จริง

## ยังไม่เสร็จ / ยังไม่พิสูจน์

- การเปลี่ยนรอบผ่านส่วนขยายบน TTM จริง
- การกรอกจำนวน เลือกที่นั่ง และล็อกที่นั่งบน TTM จริง ช่องจำนวนใน popup เป็นเพียงแผน ยังไม่กรอกลงเว็บ
- ขั้นตอนจองจริง การจัดการข้อผิดพลาด และผลลัพธ์ครบเส้นทางบนงานเป้าหมาย
- การเชื่อมจอง AllTicket
- ประสิทธิภาพวันเปิดขายหรือโอกาสได้บัตร
- การอัปโหลดโค้ดล่าสุดขึ้น GitHub: ไม่มี URL repository ให้ตรวจ จึงยังไม่ยืนยันว่า remote ตรงกับไฟล์ชุดนี้

ไม่มีฟังก์ชันเจาะระบบ ข้ามคิว ปลอมสิทธิ์ แก้ CAPTCHA หรือ API ซื้อบัตรภายใน
