# TTM Reader รุ่นทดลอง 0.2.0

เป้าหมายของรุ่นนี้คือพิสูจน์ว่า extension อ่านชื่องานและรอบจากแท็บ TTM ที่ผู้ใช้เปิดไว้ได้ ไม่ใช่บอตจองบัตรอัตโนมัติ

## ก่อนอัปเดต: สิทธิ์ที่เปลี่ยน

เพิ่ม `activeTab` และ `scripting` ให้ Chrome อนุญาตเข้าถึงแท็บชั่วคราวเมื่อคุณเรียกส่วนขยาย โค้ดรับเฉพาะหน้า HTTPS บน `booking.thaiticketmajor.com/booking/3m/zones.php` เท่านั้น หน้าคิว เลือกที่นั่ง ชำระเงิน หรือโดเมนอื่นจะหยุด ไม่มีสิทธิ์ cookies, debugger, storage, webRequest หรือ all_urls และไม่มี TTM host permission ถาวร

การอ่านยังไม่เริ่มเมื่อเปิด popup ต้องกดปุ่ม “ตรวจชื่องานและรอบจากแท็บนี้” ก่อน ไม่อ่านข้อมูลบัญชีหรือ hidden fields ไม่ส่งข้อมูลออก ไม่เก็บ query parameters ของ URL ที่อาจมี token

## วิธีอัปเดตและตรวจจริง

1. ใช้ไฟล์รุ่น 0.2.0 แทนโฟลเดอร์ extension ที่เคยติดตั้ง ถ้าเคย Load unpacked จากโฟลเดอร์ `ticket-lab/extension` ใน workspace นี้ ไฟล์ถูกอัปเดตแล้ว
2. เปิด `chrome://extensions` ดูรายการ Ticket Pilot แล้วกด Reload (ลูกศรวน) หาก Chrome ขอเปิดใช้งานหรือยืนยันสิทธิ์ใหม่ ให้คุณอ่านและตัดสินใจเอง
3. ตรวจว่ารายการเป็น **Ticket Pilot — Lab & TTM Reader 0.2.0** ถ้ายัง 0.1.0 แสดงว่าติดตั้งจากโฟลเดอร์อื่น ต้องแทนไฟล์ในโฟลเดอร์นั้น หรือ Load unpacked จากโฟลเดอร์รุ่นใหม่
4. เปิดหน้าเลือกรอบ/โซน TTM ที่คุณล็อกอินไว้ แล้วคลิกไอคอน Ticket Pilot บน toolbar
5. กด **ตรวจชื่องานและรอบจากแท็บนี้** ตรวจว่าชื่องานและรายการรอบตรงกับหน้าเว็บ ป้ายต้องระบุ “อ่านจากแท็บ TTM จริง”
6. หากต้องการเลือกรอบ เลือกใน dropdown ของ popup แล้วกด **เลือกรอบนี้บนหน้าเว็บ · ยังไม่จอง** หน้าของ TTM อาจเปลี่ยน/โหลดใหม่ตามปกติ ให้กดตรวจใหม่ก่อนทำอย่างอื่น
7. ตารางคงเหลือจะอ่านเฉพาะที่มองเห็น ถ้าต้องการข้อมูลนี้ ให้คุณเปิดปุ่ม **ที่นั่งว่าง** บน TTM เอง แล้วเปิด popup กดตรวจอีกครั้ง

ช่องจำนวน 2 ใบเป็นเพียงแผนในแผง **ไม่ได้กรอกจำนวนหรือเลือกที่นั่งบน TTM** การเลือกรอบนี้ไม่ได้ยืนยันซื้อ ไม่มีปุ่มชำระเงินหรือ auto checkout

## การตรวจสอบที่ทำแล้วและที่ยังต้องทำ

- ตรวจ syntax และ automated tests เรื่อง allowed host/path, ไม่ส่ง token ในผลตรวจ, ไม่มีการเปลี่ยนค่าขณะ inspect, stale snapshot, disabled/ambiguous controls และการหยุดบนหน้า login/queue
- หน้าอ้างอิงใน `http://127.0.0.1:5208/ttm-fixture` ใช้โค้ดเดียวกับ popup/adapter พร้อมป้าย FIXTURE ให้ทดสอบ UI และเหตุการณ์เปลี่ยนรอบ โดยไม่มีคำขอจอง
- **ผล fixture ไม่ใช่การยืนยันบนเว็บไซต์จริง** หลังผู้ใช้อนุญาต ได้ Reload เป็น 0.2.0 ใน Chrome และกดตรวจบนแท็บ TTM จริงสำเร็จแล้ว (30 ต.ค. 2569): อ่านชื่อ Moonshadow : The Afterglow Fan Party and After Party (Rerun), รอบ FAN PARTY ที่เว็บเลือกอยู่ และตาราง RERUN E-TICKET: Available ไม่เปลี่ยนรอบ ไม่เลือกที่นั่ง และไม่สร้างรายการจอง การเลือกรอบผ่าน popup บน TTM จริงยังไม่ได้ทดสอบ
- ไม่ตรวจ API ภายใน ไม่ส่ง request ซื้อหรือกดปุ่มรับคิว ไม่แก้ CAPTCHA หรือสถานะสิทธิ์
- ถ้าหน้า TTM ไม่ตรงรูปแบบที่รองรับ จะรายงานหยุดโดยไม่เดาช่องอื่น

## เมื่อพบปัญหา

ส่งเฉพาะข้อความสถานะและภาพ popup ที่ปิดข้อมูลส่วนตัว อย่าคัดลอก URL ที่เพิ่มพารามิเตอร์ session/token หลังล็อกอิน และอย่าส่งคุกกี้หรือรหัสผ่าน

## ผลตรวจรุ่น 0.2.0

Automated tests ผ่าน 18 กรณี และตรวจ popup ใน Chrome ที่ติดตั้งจริงสำเร็จบนหน้างานข้างต้น ผลนี้ยืนยันเฉพาะการอ่านชื่องาน/รอบ/ตารางที่มองเห็น ไม่ใช่การทดสอบซื้อบัตร และไม่รับรองทุกงานหรือระบบคิววันขาย
